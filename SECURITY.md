# Security policy

This repository documents Abnormal Mail Server, an Abnormal-owned fork updated from Stalwart v1.1.1. It does not promise upstream Stalwart support dates or response times. Consult the release notes for the exact fork version in use.

## Reporting a vulnerability

Do not post vulnerability details in a public issue or discussion. If GitHub private vulnerability reporting is enabled for [abnormalhq/stalwart](https://github.com/abnormalhq/stalwart), use that channel. If it is unavailable, do not send the report to upstream Stalwart or publish it publicly; repository owners must provide an approved private reporting channel before accepting reports.

Please include the affected fork version, reproducible steps, impact, and any relevant configuration with secrets removed. Do not include credentials or customer data.

## Upstream separation

This fork's security reports must not be sent to Stalwart Labs, upstream support, or the upstream repository. Upstream security policies apply only to the upstream project.
